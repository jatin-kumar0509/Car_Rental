# Drift

Drift is a UIKit car-rental app prototype for iOS 15+.

## Included flow

- Browse a local fleet with search and category filtering
- Open a car detail page with vehicle specs
- Select pickup and return dates with live pricing
- Reserve a car and view it in My bookings
- Profile screen with common account shortcuts

## Run

Open `CarRentalApp.xcodeproj` in Xcode on macOS, select an iPhone simulator, and press Run. The app uses only UIKit and Foundation, so there are no package dependencies or API keys required.
